Задача 1: Система курьерской доставки (Dostavator)

Цель: Отработать абстрактные классы, наследование и базовый полиморфизм.

Легенда: Ты пишешь ядро для приложения курьерской доставки. У тебя есть разные типы доставок, и каждая рассчитывает свою стоимость по-своему, но все они должны управляться из одного списка заказов.

Требования:

    Создай абстрактный класс DeliveryTask.

        Инкапсуляция: Добавь приватные поля basePrice (базовая цена), distance (расстояние), weight (вес). Сделай для них геттеры, но запрети менять вес и расстояние после создания объекта (напиши конструктор без сеттеров).

        Добавь абстрактный метод calculateTotalCost().

    Создай три класса-наследника:

        StandardDelivery (обычная доставка): стоимость = basePrice + (distance * 10).

        ExpressDelivery (срочная доставка): стоимость = (basePrice + (distance * 10)) * 2.

        HeavyCargoDelivery (грузовая доставка): добавляется наценка за каждый килограмм свыше 15 кг.

    Полиморфизм в действии: Создай класс Dispatcher, в котором есть метод printDailyReport(List<DeliveryTask> tasks). Пройдись циклом по списку доставок (среди которых будут и экспресс, и стандартные) и вызови у каждого calculateTotalCost(), подсчитывая общую выручку.
