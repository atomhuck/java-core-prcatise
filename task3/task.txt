Задача 3: Анализатор Big Data для E-commerce

Цель: Объединить всё вместе (Абстрактные классы + Интерфейсы + Полиморфизм + Инкапсуляция).

Легенда: Твоя система получает огромные массивы сырых данных от интернет-магазина. Данные бывают двух типов: "Действия пользователей" (клики, просмотры) и "Финансовые транзакции" (покупки, возвраты). Их нужно по-разному анализировать и выгружать в HDFS (Hadoop Distributed File System).

Требования:

    Создай интерфейс Exportable с методом exportToHDFS().

    Создай абстрактный класс DataAnalyzer, который реализует интерфейс Exportable.

        Добавь в него защищенное (protected) поле String rawData.

        Напиши общий метод validateData(), который проверяет, не пустая ли строка (базовая логика для всех).

        Объяви абстрактный метод analyze().

    Создай наследников: UserActivityAnalyzer и FinancialTransactionAnalyzer.

        Переопредели метод analyze(). Финансовый анализатор должен искать в строке суммы покупок, а анализатор активности — подсчитывать клики (сымитируй эту логику через System.out.println).

        Переопредели метод exportToHDFS() (пришедший из интерфейса), чтобы каждый класс рапортовал о выгрузке своего типа данных.

    В main создай массив типа DataAnalyzer[]. Положи туда разные анализаторы. В цикле у каждого вызови сначала validateData(), затем analyze(), а потом exportToHDFS().
