Задача 2: Мультиплатформенный бот-загрузчик

Цель: Отработать интерфейсы и сокрытие реализации (слабую связанность).

Легенда: Твоя программа должна принимать ссылки на видеоролики из разных социальных сетей и скачивать их. Логика скачивания для каждой платформы абсолютно разная, но основному механизму бота должно быть всё равно, откуда качать.

Требования:

    Создай интерфейс VideoDownloader с методом download(String url).

    Создай классы-реализации: TikTokDownloader и InstagramDownloader. Пусть пока их методы download просто выводят в консоль имитацию работы (например: "Подключение к API TikTok... извлечение токена... скачивание").

    Инкапсуляция: Внутри каждого загрузчика спрячь приватные методы (например, extractVideoId(String url) или bypassSecurity()), которые нужны только этому классу. Снаружи должен быть виден только метод download.

    Создай класс BotMessageProcessor. У него должен быть метод processMessage(String message).

        Логика: метод анализирует текст сообщения. Если видит ссылку на TikTok, он создает объект TikTokDownloader, но кладет его в переменную типа VideoDownloader. Затем вызывает метод скачивания.
